## Headroom + Codex

[Headroom](https://github.com/headroomlabs-ai/headroom) integrado como ferramenta
de desenvolvimento, com versao fixada e ambiente Python isolado.

```powershell
python headroom_codex.py install
python headroom_codex.py check
python headroom_codex.py run
```

O ultimo comando inicia uma nova sessao do **Codex CLI** pelo proxy local.
Nao ativa automaticamente a compressao no aplicativo Codex ja aberto.

Guia de uso, MCP no desktop, credenciais e limitacoes: [Headroom](HEADROOM.md).
